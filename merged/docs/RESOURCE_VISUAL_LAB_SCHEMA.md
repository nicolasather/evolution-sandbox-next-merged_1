# Resource Visual Lab — plate-spec schema

Generated by `npm run lab:schema` from `lib/devlab/components`. Do not edit by hand.

The model returns ONE JSON object (never code, never SVG). It is validated by `lib/devlab/schema.ts`: unknown components,
wrong types and missing required numbers are errors; out-of-range numbers are clamped with a warning.

```json
{ "title": "string", "layers": [ { "z": 0, "parts": [ { "c": "<component id>", "x": 50, "y": 50, "rot": 0, "s": 1, "flip": false, "w": "main", "o": 1, "p": { } } ] } ] }
```

| limit | value |
|---|---|
| layers | ≤ 6 |
| parts per layer | ≤ 20 |
| parts total | ≤ 40 |
| layer z | −14 … 14 |
| x, y | ±160 |
| weights `w` | bold, main, fine, hair |

Parameter notation: `name:type[min..max]=default`; `!` marks a required parameter.
