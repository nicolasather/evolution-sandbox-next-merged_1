# Quiz Studio redesign — implementation ledger (18 Oct 2026)

Scope: `merged/app/quiz/**`, `merged/components/quiz/**`, `merged/lib/quiz/**`, `merged/public/quiz/**`. Nothing outside Quiz Studio was changed.

## Audit (what actually exists)
- Routes: `/quiz`, `/quiz/library`, `/quiz/my`, `/quiz/new`, `/quiz/edit/[id]`, `/quiz/setup/[id]`, `/quiz/host/[id]`, `/quiz/play/[id]`, `/quiz/join`, `/quiz/login`, `/quiz/keep`, `/quiz/auth/confirm` (+ new `/quiz/modes`).
- There is **one game mode, Classic Quiz**, played three ways: Play solo, Classroom projector, Online multiplayer (`lib/quiz/types.ts`, `lib/quiz/compatibility.ts`). Tower Defense / Obstacle Survival / Clue Racing do not exist in Quiz Studio, so no such modes were invented; the art panels belong to the three real play methods.
- Guest sessions already existed server-side (`/api/quiz/auth/anonymous`, Supabase anonymous sign-in). What blocked guests was `requireUserOrRedirect` on `/quiz/new` and `/quiz/my`, plus a consent checkbox on the login page.

## Scroll bug — root cause and fix
`app/_design-system.css` (the game) sets `html{height:100%;overflow:hidden}` and `body{height:100%;overflow:hidden}`. `/quiz` inherited it, so the document could not scroll; zooming out only enlarged the viewport inside the same clip. Fix in `app/quiz/quiz.css`: `html:has(.qz){height:auto;overflow-y:auto}` and `html:has(.qz) body{height:auto;overflow:visible}`. `:has()` is evaluated live, so client navigation back to the game restores the lock (verified). No fixed-stage locking is needed on quiz pages. The game's custom cursor (which hides the native one) and decorative fixed layers are switched off only while `.qz` is mounted.

## Guest creation
- `/quiz/new` and `/quiz/edit/local-*` render the editor with no auth.
- `lib/quiz/local-drafts.ts`: versioned (`qz:drafts:v1`) device storage with memory fallback, quota/blocked detection, export as JSON, never deletes by itself.
- `lib/quiz/session-client.ts`: `ensureCloudSession()` resolves an existing session or starts one anonymous session (one shared in-flight request, failure remembered per tab). Used lazily, only when a draft validates.
- Editor autosave (1.2 s debounce): device copy first, then online when possible. A published quiz is never auto-overwritten; Save Draft / Publish are explicit. After a confirmed online save the device copy is removed (migration). Unsaved changes for an online quiz are offered back ("Restore / Discard") if newer than the server copy.
- My Quizzes lists device drafts with "Save Online" (explicit migration, device copy removed only after the server confirms), Export Backup, confirmed Delete.
- Server rules are unchanged: owner is always the authenticated user, rate limits, guest cap of 20 quizzes, `saveQuizSchema` validation.

**Only external step (optional):** to let guests save online, enable *Authentication → Sign In / Providers → Allow anonymous sign-ins* in the Supabase dashboard. Until then everything works from the device and the UI says so; no RLS change is made or needed.

## Design system
Tokens and components in `app/quiz/quiz.css` (scoped `.qz`). Fonts self-hosted in `public/quiz/fonts/` (Barlow Condensed, Atkinson Hyperlegible — SIL OFL, licenses included). Scenes: `public/quiz/art/*.svg`, generated by `tools/quiz-art/generate.mjs` (`node tools/quiz-art/generate.mjs`). All art is original, face-free, with no baked-in text.

## Not changed
Gameplay semantics, scoring, modifiers, slot limits, rooms/submit APIs, database, RLS, auth integration.
