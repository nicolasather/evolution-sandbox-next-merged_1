# Pacing and retention without compulsive loops

Session lengths 15/20/30/45 min; sample balanced 15-minute allocation: 8–10 minutes quiz/reveal, 3–5 minutes objectives, <=2 minutes lobby/drafts. Planner uses question-kind budget: Multiple Choice ~25–40 s, Truth Hunt ~20–30 s, Answer Forge ~35–55 s, Connection Rush ~45–75 s, Fill Table ~50–90 s. Read-aloud extends time. Always show actual estimate, warn if quiz too short, never pad with made-up questions.

An episode runs 45–90 seconds for 15-minute matches and 70–140 seconds for 30–45 min matches; adapt number of episodes. Provide one meaningful interactive objective change each episode, not unrelated randomness. Session ends with a positive learning recap, awards for accurate thinking and team contributions, not addictive streaks. Avoid manipulative daily reward triggers.
