# End-to-end user journeys

**Teacher**: select Arena Clash first → compatible modifiers → choose existing published quiz → choose Control/Relay/Crystal → pick teams, duration, difficulty/pressure → map and readability → real question-kind preflight → create room → show join code/projector → start after ready → can pause, resume, extend, moderate, end → see results and question learning report. Creation must never silently require students to have email accounts.

**Student**: open join → enter 6-char code and nickname → recover prior seat when reconnecting → choose team/role in lobby → practice basic movement → start quiz, world frozen → answer → live objective arena → spend points in planning → repeat → results and teacher-approved review.

**Projector**: beautiful readable overview with 3-4 team scores, active zone, objective progress, question stage only when teacher permits; privacy-safe aliases; never reveal individual correctness before question close. Empty and lost-socket states styled and helpful.

**Practice**: local no-login arena with deterministic scripted objectives, sample quiz of all five kinds, no persistence/rewards; same pure engine. A fair demo that doesn't imply real participants.
