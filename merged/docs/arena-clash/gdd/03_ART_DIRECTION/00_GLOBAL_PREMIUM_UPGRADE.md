# Global premium upgrade standard for Games 1, 2, and 4

This document supersedes any earlier assumption that the current art quality of Tower Defense or Swarm Survival is already acceptable.

## The new bar
The premium online modes must feel like:
- original,
- lovingly illustrated,
- richly animated,
- playful for kids,
- simple to read,
- and obviously more polished than a classroom website demo.

## What is not enough anymore
The following are now considered below target:
- broad flat playfields with minimal scenic richness,
- mostly static actors with only basic movement,
- too many always-visible utility buttons,
- UI that feels like page furniture rather than part of a game,
- worlds that feel too small.

## The target mood
Think:
- a storybook world with place identity,
- bright arcade charm,
- readable chunky silhouettes,
- compact but satisfying effects,
- motion that teaches what is happening.

## Required cross-game changes
### Environmental density
- More landmarks.
- More edge detail.
- Better sense of location.
- Stronger map variety.

### Motion
- More anticipation.
- Better impact.
- Clearer transition timing.
- Better milestone animation (unlocks, waves, objectives, results).

### HUD reduction
- Default HUD should be compact.
- Utility functions hidden behind a menu or drawer.
- The world should have more visual room.

### Large spaces where appropriate
- Especially for Swarm Survival, world size must increase materially.

### Consistency
- Tower Defense, Swarm Survival and Arena Clash should each have their own identity, but the quality bar and handcrafted feel must be consistent.
