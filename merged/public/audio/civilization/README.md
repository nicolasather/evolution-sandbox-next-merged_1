# Civilization: Lifelines — narration audio

**No recorded narration ships with this build.** Every authored line (24 chapters × intro/success/warning) is
shown as a subtitle. Audio is optional and, today, comes only from the player's own browser speech voices when
they enable it in Settings.

To add licensed recordings later:
1. Place files here, e.g. `first-light-intro.mp3`.
2. Add `{ "cueId": "first-light:intro", "file": "first-light-intro.mp3", "licence": "<who/under what terms>" }`
   to `manifest.json`.
3. Only then does the in-game asset status read `recorded`. Never add a file without a licence note.
